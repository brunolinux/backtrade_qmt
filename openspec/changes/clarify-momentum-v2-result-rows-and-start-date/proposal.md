# Proposal

## Why

v2 回测将持仓和权益报表行保存为匿名元组，结果构造函数另行手写列名及顺序，字段变化容易造成两处定义不一致。工作区中起始日期已用于筛选时间线，但循环内仍保留旧判断；字符串日期会与 `Timestamp` 比较而报错。

## What Changes

- 为持仓快照行和权益行引入具名、不可变的字段类型，使构造和读取代码直接表达字段含义。
- 由行类型统一提供三张结果表的列顺序；结果构造函数继续明确日期索引和空表结构。
- 在预处理后筛选回测时间线，删除循环内重复且类型不兼容的起始日期判断。
- 更新相关类型说明和测试，保持三张结果表、空表、交易顺序、日志及 CSV 输出兼容。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无。本次修复工作区中的日期回归并重构内部行表示，恢复和保持现有 `strategy-state-transitions` 兼容性约定；不改变规范要求。

## Impact

涉及 `strategy_common.py` 的持仓快照行、`strategy_momentum_v2.py` 的权益行和结果构造、相应单元测试。`backtest` 公开参数与三张 DataFrame 的列、索引、数值及导出脚本保持不变；不引入新依赖。
